关于微形

微形收录了 Blender Cell Biology skill 制作的模型和动画。

分子模型沿用公开结构中的亚基位置。你可以转动整套装配，也可以移开遮挡，单独观察一个亚基。超净工作台则从整机展开到七个部件组。

每件作品都附有建模依据。模型的拆解间距和机制短片的节奏用于讲解结构与过程。
